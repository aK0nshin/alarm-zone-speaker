# alarm-zone-speaker

Лаконичное и изолированное решение для циклического воспроизведения аудио на плате **ESP32-C3 Super Mini**. Звук генерируется нативно через аппаратный ШИМ-контроллер (`LEDC`) и выводится напрямую на **GPIO3** без внешних ЦАП (DAC). Среда разработки полностью скрыта в Docker, операционная система компьютера остаётся чистой.

## Как это работает

1. **Аппаратный ШИМ:** Программа считывает сырые 8-битные аудиоданные из встроенной памяти чипа и напрямую отдаёт их контроллеру `LEDC`, который формирует аналоговую звуковую волну методом высокочастотного переключения.
2. **Файловая система (SPIFFS):** Звуковой файл хранится в выделенном секторе Flash-памяти чипа в несжатом формате WAV.
3. **Неблокирующий цикл:** Повтор трека и двухсекундная пауза между циклами реализованы на программных таймерах микросекунд. Во время паузы ШИМ-канал полностью отключается от пина, чтобы динамик не гудел в тишине.

## Схема подключения

Для сглаживания цифрового ШИМ-сигнала в чистый звук между платой и усилителем обязательно ставится простейший RC-фильтр низких частот.

```text
[ ESP32-C3 Super Mini ]                      [ Усилитель Звука ]
GPIO3 (нога 3) --------[ Резистор 1 кОм ]------> IN (Сигнал)
                                     |
                           [ Конденсатор 10 нФ ]
                                     |
GND ---------------------------------+---------> GND (Земля)
5V  -------------------------------------------> VCC (Питание)
```

## Подготовка аудиофайла

Исходный трек нужно перевести в несжатый моно-формат **WAV (8-bit Unsigned PCM)** с частотой дискретизации **22050 Гц**. Назови исходник `source.mp3`, положи в корень проекта и выполни конвертацию через встроенный в контейнер **FFmpeg**:

```bash
ffmpeg -i source.mp3 -acodec pcm_u8 -ac 1 -ar 22050 data/sound.wav -y
```

## Инструкция по сборке

### 1. Файлы конфигурации
В корне проекта создай два файла:

**`Dockerfile`**
```dockerfile
FROM ubuntu:24.04
ENV DEBIAN_FRONTEND=noninteractive
RUN apt-get update && apt-get install -y python3 python3-pip git curl ffmpeg \
    && apt-get clean && rm -rf /var/lib/apt/lists/*
COPY --from=ghcr.io/astral-sh/uv:latest /uv /uvx /bin/
RUN uv venv /opt/pio-env && . /opt/pio-env/bin/activate && uv pip install -U platformio
ENV PATH="/opt/pio-env/bin:$PATH"
WORKDIR /workspace
CMD ["/bin/bash"]
```

**`platformio.ini`**
```ini
[env:esp32-c3]
platform = espressif32
board = esp32-c3-devkitm-1
framework = arduino
monitor_speed = 115200
board_build.filesystem = spiffs
build_flags =
    -D ARDUINO_USB_MODE=1
    -D ARDUINO_USB_CDC_ON_BOOT=1
    -D CORE_DEBUG_LEVEL=3
```

### 2. Сборка контейнера (Выполняется один раз)
Открой **Windows PowerShell** в папке проекта и собери образ компилятора:

```powershell
docker build -t pio-esp32 .
```

### 3. Компиляция в 1 клик
Запусти сборку из **PowerShell** одной командой:

```powershell
docker run --rm -it -v "${PWD}:/workspace" pio-esp32 /bin/bash ./rebuild.sh
```

Контейнер соберёт бинарники и сам удалится из памяти. Результаты запишутся в папку `.pio/build/esp32-c3/`.

## Инструкция по прошивке

Заливка файлов происходит через браузер Chrome/Edge на сайте **[ESP Web Flasher](https://github.io)**.

1. Подключи плату по USB и нажми **Connect**. Выбери чип **ESP32-C3**.
2. **Критично:** Измени выпадающий список **Flash Mode** на значение **`dio`**.
3. Если шьёшь первый раз или менял разметку: нажми **Erase Flash**.
4. Добавь два файла из папки сборки по следующим адресам:
   * **`firmware.bin`** — адрес **`0x10000`**
   * **`spiffs.bin`** — адрес **`0x290000`**
5. Нажми **Program**.

## Мониторинг дебага

Плата использует встроенный USB-CDC. Чтобы увидеть логи:

1. Спустись на сайте прошивки к разделу **Console**.
2. Поставь скорость **115200** и нажми **Start**.
3. Нажми физическую кнопку **RST** на плате. Через 4 секунды безопасной паузы инициализации порта в окне побегут системные логи монтирования диска и запуска плеера.
