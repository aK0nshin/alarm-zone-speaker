# Правила проекта

- Общение и документация на русском.
- Ограничивать изменения текущей задачей.
- Не перезаписывать и не отменять незавершённые изменения пользователя.

## Стиль кода

- Придерживаться принципов SOLID. Разделять ответственность и зависимости без избыточных абстракций.
- Использовать ранний выход из функций для ошибок, некорректных входных данных и случаев, не требующих обработки. Избегать лишней вложенности.
- Оставлять минимум комментариев: только для неочевидных мест, причин решений и ограничений. Не пересказывать код комментариями.
- Следовать существующим соглашениям проекта об именовании и форматировании.

## Железо и сборка

- Целевая плата: ESP32-C3 Super Mini.
- Окружение PlatformIO: `esp32-c3`.
- Для используемой платы требуется Flash Mode `dio`.
- Не менять распиновку и разметку Flash без согласования.
- Команды сборки и прошивки приведены в [README.md](README.md).

## Документация

- README описывает назначение и целевое поведение устройства, сборку и прошивку.
- Не включать в README временный статус разработки.
- Не дублировать в README детали реализации, которые часто меняются.

## Проверка

- После изменения кода проверять сборку.
- Сообщать, какие проверки выполнены, а какие нет. При невозможности проверки указывать причину.
- Не прошивать подключённое устройство без явного запроса пользователя.
